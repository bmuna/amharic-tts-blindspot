# Pair name legend

Each pair is **one identical spelling**. Contrast is spoken only:
- **stressed** = **gemination** = ጠብቆ (held / doubled consonant)
- **relaxed** = **non-gemination** = ላልቶ

Not English syllable stress. Not different written forms.

Example of the same idea: **አለ** can mean “he said” or “there is,” depending on gemination vs non-gemination.

| Folder/file prefix | Amharic word | Gemination (stressed) | Non-gemination (relaxed) |
|---|---|---|---|
| wana | ዋና | key / important | swim |
| sefi | ሰፊ | wide | tailor's shop |
| gena | ገና | Christmas game (gena) | yet / still |
| ayat | አያት | grandparent | looked intently |
