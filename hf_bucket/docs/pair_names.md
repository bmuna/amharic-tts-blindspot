# Pair name legend

Each pair is **one identical spelling**. Contrast is spoken only:
- **stressed** = ጠብቆ (held / geminated)
- **relaxed** = ላልቶ (not held)

Not different written forms. Example of the same idea: **አለ** can mean “he said” or “there is,” depending on how it is said.

| Folder/file prefix | Amharic word | Stressed (ጠብቆ) meaning | Relaxed (ላልቶ) meaning |
|---|---|---|---|
| wana | ዋና | key / important | swim |
| sefi | ሰፊ | wide | tailor's shop |
| gena | ገና | Christmas game (gena) | yet / still |
| ayat | አያት | grandparent | looked intently |

File patterns:
- `human_recordings/{name}_stressed.m4a` / `{name}_relaxed.m4a`
- `tts_single_generation/{name}_stressed.wav` / `{name}_relaxed.wav`
- `tts_five_repeats/{name}_stressed_v1.wav` ... `_v5.wav`
